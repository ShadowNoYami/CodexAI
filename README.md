# CodexAI — Интеллектуальный ИИ-ассистент для работы с документами (RAG & Vision OCR)

Кроссплатформенное приложение на **Flutter** (Web, Windows, macOS, Linux, Android, iOS), разработанное по принципам **Feature-First Clean Architecture**. Предназначено для загрузки, парсинга, оптического распознавания (Vision OCR), семантического чанкинга и глубокого ИИ-анализа документов.

---

## Основные возможности

- **Мультиформатная загрузка документов (до 100 МБ):**
  - `PDF` (постраничное извлечение текста через `Syncfusion Flutter PDF` + автоматический **Vision OCR** для отсканированных книг и документов без текстового слоя).
  - `DOCX` (распаковка ZIP/XML и автоматическая конвертация таблиц Word в Markdown-таблицы).
  - `CSV` (автоопределение разделителей `,`, `;`, `\t` и форматирование в Markdown-таблицы).
  - `TXT` и `MD`.
- **Сканирование документов камерой телефона и из галереи (Vision OCR):**
  - Съемка договоров, чеков, прайс-листов и страниц книг через камеру (`image_picker`) с распознаванием текста и таблиц через мультимодальную модель **Gemini Vision (`gemini-3.5-flash`)**.
- **Адаптивный Гибридный RAG (Retrieval-Augmented Generation):**
  - **Full-Context Stuffing** для документов до $30\,000$ токенов и глобальных режимов анализа.
  - **Hybrid RAG (BM25 + Cosine Similarity)** в фоновом изоляте (`Isolate`) для больших документов с точным цитированием источников и номеров страниц (`[Имя_файла, Стр. X]`).
- **3 специализированных аналитических режима:**
  1. **Вопрос-ответ (RAG)** — ответы строго по тексту документа с кликабельными ссылками на страницы.
  2. **Краткая выжимка (Executive Summary)** — структурированное резюме (`TL;DR`, тезисы, цифры/даты, выводы).
  3. **Глубокий анализ** — сводная таблица метрик и KPI, поиск противоречий между разделами и карта рисков.
- **Потоковая генерация ответа (SSE Streaming):**
  - Отображение ответа ИИ токенами в реальном времени с поддержкой Markdown, таблиц и копирования блоков кода.
- **Неблокирующая обработка в `Isolate`:**
  - Передача тяжелых файлов через `TransferableTypedData` (zero-copy) без просадки FPS пользовательского интерфейса.
- **Локальное хранилище (`Drift / SQLite`):**
  - Сохранение истории сессий чатов, сообщений с цитатами и кэша распарсенных чанков документов.

## Архитектура проекта (`lib/`)

```text
lib/
├── main.dart
├── app.dart
├── core/
│   ├── config/          # EnvConfig, GoRouter
│   ├── database/        # AppDatabase (Drift / SQLite) + схемы таблиц
│   ├── error/           # Исключения (AppException) и ошибки (Failure)
│   ├── network/         # Dio клиент + SseStreamTransformer
│   ├── theme/           # Адаптивная тема Material 3 (Light & Dark)
│   └── utils/           # IsolateRunner (TransferableTypedData), TokenEstimator
└── features/
    ├── documents/       # Выбор файлов, Камера/Галерея, Парсеры, Vision OCR, Чанкинг, Предпросмотр
    ├── ai_engine/       # Системные промты, Гибридный RAG (BM25 + Cosine), LLM SSE-стриминг
    └── chat/            # Сессии чатов, активный диалог, Markdown-пузыри, быстрые действия
```
